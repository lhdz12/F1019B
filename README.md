## Descripción 

Este repositorio contiene dos simulaciones desarrolladas en Python relacionadas con fenómenos físicos clásicos:
- La simulación de la gota de Millikan, centrada en el movimiento de una gota cargada dentro de un campo eléctrico.
- La simulación de un circuito RC, mostrando la evolución del campo eléctrico y voltaje con respecto al tiempo.

Además, se incluye un pequeño archivo de reporte con notas del experimento/simulación.
